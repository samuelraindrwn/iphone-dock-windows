# Panduan iDock for Windows

iDock menampilkan layar iPhone/iPad dan menyediakan kontrol mouse/keyboard dari Windows. **Versi 0.5.0 masih eksperimental**; dukungan iPad dan kompatibilitas lintas perangkat belum terverifikasi.

Mulai melalui [README](README.md), kemudian pilih panduan sesuai kebutuhan:

1. [Instalasi dan build dari source](docs/INSTALL.md): persyaratan .NET, penyusunan paket, dan pemilihan lokasi instalasi.
2. [Cara menggunakan aplikasi](docs/USAGE.md): mirroring, pemasangan Bluetooth, pemilihan target, sensitivitas, dan orientasi.
3. [Pemecahan masalah](docs/TROUBLESHOOTING.md): aplikasi tidak terbuka, kontrol belum terhubung, keterlambatan, dan pelaporan bug.
4. [Checklist pengujian perangkat nyata](docs/STABILITY-TESTS.md): target pengujian, bukan klaim hasil.
5. [Arsitektur](docs/ARCHITECTURE.md) dan [roadmap](docs/ROADMAP.md): implementasi saat ini dan rencana pengembangan.

Jalankan **seluruh paket**, bukan EXE saja. Pilih lokasi instalasi tetap sebelum menyiapkan Bonjour/mirroring. **Ctrl + Alt + Q** mengembalikan target input ke Windows; periksa target sebelum mengetik informasi sensitif.
