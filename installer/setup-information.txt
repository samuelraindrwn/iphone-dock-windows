iDock for Windows

Mirror your iPhone or iPad to Windows and use a compatible Bluetooth adapter for mouse and keyboard control.

Setup includes the application, its .NET runtime, AirPlay receiver, Bluetooth backend, licenses and developer source. No SDK or manual build is needed to use the installed application.

Connect the computer and Apple device to the same trusted local network. Setup adds two iDock AirPlay Firewall rules for the Private profile and local subnet. It never disables the Firewall or changes the network profile. Managed or guest networks may require administrator assistance.

The optional Public Wi-Fi task on the next page is CHECKED BY DEFAULT on a fresh 0.5.3 installation. It remains visible and you can uncheck it before continuing. Upgrades and repeat Setup runs retain the previous task choice, including a previous opt-out. When selected, it adds two separate rules only for the installed vendor\uxplay\uxplay-windows.exe: Public profile, Wireless interfaces, LocalSubnet remote addresses, TCP/UDP, and no edge traversal. It applies to ALL current and future Public Wi-Fi networks, not only the current Wi-Fi name. Nearby peers on those local networks may reach the AirPlay receiver while it is running. Uncheck the task if you do not want this permission; use the receiver only on networks you trust. It does not grant access through Public wired connections or change Windows network trust.

To revoke the optional access, run Setup again and uncheck the Public Wi-Fi task, or uninstall iDock. Setup removes only its exact, unmodified optional rules; if an administrator has changed them, Setup stops for review instead of overwriting them. Uninstall preserves modified or unrelated rules. Independently created troubleshooting rules are not managed by this installer.

When you first open mirroring, UxPlay may ask to install Bonjour Service with a separate Windows administrator prompt. Follow that upstream prompt if you trust this package. An existing Bonjour service is left unchanged by Setup. Bluetooth pairing and enabling AssistiveTouch on the Apple device are still necessary for control.

If the Apple device's onscreen keyboard stays hidden after Bluetooth control connects, enable Show Onscreen Keyboard in its AssistiveTouch settings, then tap a text field. Input targeting Windows does not disconnect the BLE keyboard. See the included Usage guide for the full device-side steps and Apple reference; Setup does not change this preference automatically.

Compatibility and responsiveness depend on the Apple device, OS, Bluetooth adapter and local network. Support for every iOS/iPadOS version is not guaranteed. iDock is an independent project and is not affiliated with Apple.

Uninstall preserves your Bluetooth pairing and per-user settings/logs. It also retains the Bonjour executable and license because Bonjour may be shared with other applications. Do not delete a Bonjour executable while its service still points to it.
