The GStreamer tag used as the license text source identifies the origin of the **license copy**, not the GStreamer binary version included in UxPlay. Determining the versions/configurations of all native binaries remains part of the distribution audit.

Self-contained builds add .NET runtime notices in `licenses/dotnet`; installer builds add `licenses/Inno-Setup-LICENSE.txt`. The main project's MIT license remains in the package root.

The presence of license texts is not evidence that attribution or corresponding source is complete. See the [component notices](THIRD-PARTY-NOTICES.md#license-texts-and-distribution-audit) and [release checklist](RELEASING.md) before distributing binaries publicly.
