Tag GStreamer pada sumber teks lisensi adalah asal **salinan lisensi**, bukan penetapan versi binary GStreamer yang disertakan UxPlay. Penentuan versi/configuration seluruh binary native tetap menjadi bagian audit distribusi.

Hasil build self-contained menambahkan notices runtime .NET di `licenses/dotnet`; build installer menambahkan `licenses/Inno-Setup-LICENSE.txt`. Lisensi MIT proyek utama tetap berada di direktori utama paket.

Keberadaan teks lisensi bukan bukti kelengkapan atribusi atau corresponding source. Lihat [pemberitahuan komponen](../THIRD_PARTY_NOTICES.md#teks-lisensi-dan-audit-distribusi) dan [checklist rilis](../docs/RELEASING.md) sebelum mendistribusikan binary secara publik.
